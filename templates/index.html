PROJECT NOTES

About the Bloom Filter

A compact first-pass membership screen for a large URL set.

What is a Bloom Filter?

A Bloom Filter is a space-efficient probabilistic data structure for testing set membership. It can say an item is definitely absent or possibly present; it does not store the original URLs or support direct deletion.

Why use it for URL screening?

It provides a compact first-pass check across many known URL strings. A downstream system can use a possible match to decide whether to perform a separate, exact investigation.

Understanding false positives

A false positive happens when all checked bits are set by other inserted items, so a not-inserted string appears possibly present. The configured 1% is a target probability, not a per-query guarantee; actual results depend on the filter and tested data.

Advantages

  • Compact bit-array representation
  • Fast membership checks with fixed work per lookup
  • A negative result is definitive for the inserted set

Limitations

  • Positive results may be false positives
  • Inserted URLs cannot be reconstructed from the filter
  • Standard Bloom Filters do not support deletion
